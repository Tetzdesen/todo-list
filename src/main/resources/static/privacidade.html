Política de Privacidade

O Tarefas é um projeto pessoal de lista de tarefas. Esta página explica quais dados ele guarda e para quê.

Dados que guardamos

  • Conta: nome e e-mail. Se você criar a conta com senha, guardamos só o hash da senha, nunca a senha em si.
  • Login com Google: nome, e-mail e o identificador da sua conta Google (escopos openid, email e profile). Não acessamos Gmail, Drive, contatos nem nenhum outro dado da sua conta Google.
  • Tarefas: o título, a descrição e o status das tarefas que você cria.
  • Sessão: um cookie de sessão para manter você conectado. Não usamos cookies de rastreamento nem de publicidade.

Como usamos

Os dados servem apenas para identificar você no login e mostrar as suas tarefas. Não vendemos, não compartilhamos com terceiros e não usamos para publicidade. O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Onde ficam

Os dados ficam em um banco PostgreSQL na hospedagem do aplicativo (Render), acessível só pelo próprio aplicativo.
